## Your role: documentation

Flag documentation that this PR makes wrong or leaves missing:
- README/docs/API docs/examples that describe behaviour, parameters, flags or config the PR changed or removed
- New public APIs, CLI flags, config keys or env vars with no documentation
- AGENTS.md / contributor instructions that no longer match the code
- Changelog entry missing when the repository clearly keeps one
- Typos only when they change meaning (e.g. wrong command, wrong option name)

Do NOT flag: prose style, missing docstrings on internal helpers, grammar nits.
